# Как добавлять фотографии в галерею

Папка: `assets/img/gallery/`

Галерея подключена на 4 страницах: Главная, Производство, О компании, Проекты.
Фото на каждую страницу выбираются **автоматически по префиксу имени файла** —
добавили файл с нужным префиксом, пересобрали сайт — и он появился в карусели.
Убрали файл — слайд исчез. Дополнительная правка HTML не нужна.

## Формат имени файла

`<префикс>-<номер>.<расширение>`

| Префикс | Страница                 | Примеры |
|---------|--------------------------|---------|
| `home-` | Главная (`index.html`)    | `home-01.jpg`, `home-02.jpg` |
| `prod-` | Производство (`production/index.html`) | `prod-01.jpg`, `prod-02.jpg`, `prod-03.jpg` |
| `about-`| О компании (`about/index.html`) | `about-01.jpg` |
| `case-` | Проекты (`cases/index.html`) | `case-01.jpg`, `case-02.jpg` |

- **Номер** = порядок показа. Сортировка по возрастанию: `01`, `02`, `03`…
  (можно нумеровать с 01 и дальше по порядку).
- **Префикс обязателен.** Файл без префикса (`photo.jpg`) ни в одну галерею не попадёт.

## Поддерживаемые форматы

`jpg`, `jpeg`, `png`, `webp`, `avif`, `gif`, `svg`

Рекомендуется: `.jpg` или `.webp`, горизонтальные, соотношение сторон ~3:2
(например 1200×800 px).

## Alt-текст (описание для доступности и SEO)

Необязательно. При наличии берётся из `meta.json` в этой же папке:

```json
{
  "prod-01.jpg": "Сборка ГРЩ на производственной базе ИТЦ КСК",
  "case-02.jpg": "Реализованный проект — объект водоснабжения"
}
```

Если описания для файла нет, подставляется его имя.

## Как добавить или убрать фото

1. Положите файл с нужным префиксом в эту папку (или удалите лишний).
2. Пересоберите сайт:
   ```
   node scripts/build.js
   ```
3. Откройте `dist/<страница>/index.html` в браузере.

Количество слайдов считается автоматически по числу файлов с префиксом:

- **0 файлов** — блок галереи не выводится;
- **1 файл** — статичное фото без кнопок;
- **2 и более** — карусель: стрелки, точки, автопрокрутка (пауза при наведении/фокусе),
  управление с клавиатуры (←/→) и свайп на тач-экранах.

## Важно

- В именах файлов используйте только латиницу, цифры и дефис.
  Пробелы, кириллицу и спецсимволы (`%`, `&`, `+`, `№` и т.п.) не используйте —
  они ломают ссылки.
- Для одной страницы можно держать любое число файлов с её префиксом.
- После любого изменения фото нужна **пересборка** (`node scripts/build.js`).
  Исходники править не требуется.
